## Що Це

`mcp` - це starter-проект, який можна клонувати для нових внутрішніх MCP-серверів і PHP web-tooling проектів.

У шаблон вже вкладено:

| Частина | Для чого |
| --- | --- |
| `mysqly` | MySQL доступ, CRUD helpers, prepared statements |
| `phpy` | Легкий web UI без великого фреймворку |
| `clickhousy` | HTTP-клієнт для ClickHouse |
| `manticory` | SQL-клієнт для Manticore |
| `config/app.php` | Єдине місце для дефолтних налаштувань |
| `config/local.php` | Локальні секрети і override-и після `init` |
| `tasks/setup_db.php` | Автогенерація MySQL DB, user і базових таблиць |
| `/login`, `/access` | Web-авторизація і керування доступами |
| `php mcp.php serve` | MCP stdio server для інших агентів/проектів |

## Швидкий Старт

### 1. Створити новий проект після clone

```bash
git clone <repo-url> my_project
cd my_project
php mcp.php init . my_project
php tasks/setup_db.php --admin-user=root --admin-password=ROOT_PASSWORD
```

Після `init` буде створено `config/local.php` з:

- назвою проекту;
- MySQL database/user/password;
- MCP server name/title;
- bootstrap admin логіном;
- згенерованим admin password.

### 2. Створити проект з окремо склонованого starter-а

Це режим як у `phpy`: один starter може породжувати нові проекти.

```bash
git clone <repo-url> /var/apps/mcp
php /var/apps/mcp/mcp.php init /var/apps/my_project my_project
cd /var/apps/my_project
php tasks/setup_db.php --admin-user=root --admin-password=ROOT_PASSWORD
```

### 3. Запустити MCP server

```bash
cd /var/apps/my_project
php mcp.php serve
```

## Команди

| Команда | Що робить |
| --- | --- |
| `php mcp.php` | Показує CLI help |
| `php mcp.php init [dir] [name]` | Створює новий проект або локальний `config/local.php` |
| `php mcp.php init /var/apps/x x --force` | Перезаписує local config і копіює starter у непорожню директорію |
| `php mcp.php setup-db ...` | Проксі до `tasks/setup_db.php` |
| `php mcp.php serve` | Стартує MCP stdio server |
| `php tasks/setup_db.php ...` | Створює DB, user, auth tables і bootstrap admin |

## Конфігурація

Основні дефолти лежать тут:

```text
config/app.php
```

Локальні override-и і секрети лежать тут:

```text
config/local.php
```

`config/local.php` створюється командою `init` і не комітиться в git.

### Головні параметри

| Config key | Env override | Приклад |
| --- | --- | --- |
| `project.name` | `MCP_PROJECT_NAME` | `my_project` |
| `project.title` | `MCP_PROJECT_TITLE` | `MY PROJECT` |
| `mysql.host` | `MCP_MYSQL_HOST` | `127.0.0.1` |
| `mysql.port` | `MCP_MYSQL_PORT` | `3306` |
| `mysql.database` | `MCP_MYSQL_DATABASE` | `my_project` |
| `mysql.user` | `MCP_MYSQL_USER` | `my_project` |
| `mysql.password` | `MCP_MYSQL_PASSWORD` | `secret` |
| `clickhouse.url` | `MCP_CLICKHOUSE_URL` | `http://localhost:8123` |
| `clickhouse.database` | `MCP_CLICKHOUSE_DATABASE` | `default` |
| `manticore.host` | `MCP_MANTICORE_HOST` | `127.0.0.1` |
| `manticore.port` | `MCP_MANTICORE_PORT` | `9306` |
| `auth.bootstrap_admin.login` | `MCP_ADMIN_LOGIN` | `admin` |
| `auth.bootstrap_admin.password` | `MCP_ADMIN_PASSWORD` | `admin-password` |
| `mcp.allow_unsafe_sql` | `MCP_ALLOW_UNSAFE_SQL` | `0` |

### Приклад `config/local.php`

```php
<?php

return [
    'project' => [
        'name' => 'my_project',
        'title' => 'MY PROJECT',
    ],
    'mysql' => [
        'database' => 'my_project',
        'user' => 'my_project',
        'password' => 'generated-db-password',
    ],
    'auth' => [
        'bootstrap_admin' => [
            'login' => 'admin',
            'password' => 'generated-admin-password',
            'name' => 'Administrator',
        ],
    ],
];
```

## Database Bootstrap

`tasks/setup_db.php` створює:

- MySQL database;
- MySQL user;
- grants на database;
- `mcp_users`;
- `mcp_pages`;
- `mcp_user_page_access`;
- bootstrap admin user;
- базові сторінки `/` і `/access`.

```bash
php tasks/setup_db.php --admin-user=root --admin-password=ROOT_PASSWORD
```

Додаткові параметри:

| Option | Description |
| --- | --- |
| `--admin-host=127.0.0.1` | Host для root/admin MySQL підключення |
| `--admin-port=3306` | Port для root/admin MySQL підключення |
| `--admin-user=root` | MySQL admin user |
| `--admin-password=...` | MySQL admin password |
| `--db=my_project` | Назва DB, якщо треба override |
| `--user=my_project` | Назва DB user |
| `--password=...` | Password для DB user |
| `--grant-host=%` | Host у `CREATE USER user@host` |

```nginx

  root /var/apps/my_project/web;

  server_name my-project.local;

  location ~ \.php$ {
```

## Авторизація І Доступи

Система доступів побудована навколо трьох таблиць:

| Table | Зміст |
| --- | --- |
| `mcp_users` | Користувачі, password hash, role, active status |
| `mcp_pages` | Зареєстровані web pages за path |
| `mcp_user_page_access` | Який user має доступ до якої page |

Ролі:

| Role | Поведінка |
| --- | --- |
| `admin` | Має доступ до всіх сторінок і `/access` |
| `user` | Має доступ тільки до явно дозволених сторінок |

### Додати Нову Сторінку

1. Створити файл:

```text
app/reports/default.php
```

2. Додати PHPy markup:

```php
<?php

return [
    'section.page-head' => [
        ['h1' => 'Reports'],
        ['p.muted' => 'Internal reports page.'],
    ],
];
```

3. У web UI відкрити `/access`.
4. У блоці `New Page` додати:

```text
Path: /reports
Title: Reports
```

5. Видати доступ потрібним users через чекбокси.

## MCP Server

Старт:

```bash
php mcp.php serve
```

Transport: `stdio`.

Підтримані JSON-RPC methods:

| Method | Description |
| --- | --- |
| `initialize` | Повертає protocol version, capabilities і server info |
| `tools/list` | Повертає список tools |
| `tools/call` | Викликає tool |

### Tools

| Tool | Що робить |
| --- | --- |
| `app_config` | Повертає config без секретів |
| `mysql_query` | Виконує MySQL query через `mysqly` |
| `clickhouse_query` | Виконує ClickHouse query через `clickhousy` |
| `manticore_query` | Виконує Manticore SQL query через `manticory` |
| `access_list` | Повертає users, pages і access map |

`mysql_query` за замовчуванням дозволяє тільки read-only SQL:

```sql
SELECT ...
SHOW ...
DESCRIBE ...
EXPLAIN ...
```

Щоб дозволити write queries через MCP:

```bash
MCP_ALLOW_UNSAFE_SQL=1 php mcp.php serve
```

Вмикай це тільки там, де MCP-клієнту справді можна писати в базу.

### MCP Client Config Example

```json
{
  "mcpServers": {
    "my_project": {
      "command": "php",
      "args": ["/var/apps/my_project/mcp.php", "serve"]
    }
  }
}
```

## Розширення MCP Tools

Tools описані в:

```text
lib/mcp_server.php
```

Щоб додати tool:

1. Додай опис у `mcp_server_tools()`.
2. Додай route у `mcp_server_call_tool()`.
3. Реалізуй функцію, яка повертає `mcp_tool_text(...)`.

Мінімальний приклад:

```php
if ($name === 'ping') {
    return mcp_tool_text('pong', ['ok' => true]);
}
```

## Development Flow

```bash
cd /var/apps/my_project
php -l boot.php
php -l lib/mcp_server.php
php mcp.php
php mcp.php serve
```

Для web-сторінок:

1. Додати файл у `app/<page>/default.php`.
2. Зареєструвати path у `/access`.
3. Видати доступ потрібним users.
4. Перевірити сторінку в браузері.

Для DB-змін:

1. Додати bootstrap logic у `lib/auth.php` або окремий `lib/<feature>.php`.
2. Викликати bootstrap з `tasks/setup_db.php` або окремого task.
3. Тримати schema idempotent через `CREATE TABLE IF NOT EXISTS`.

## Troubleshooting

### Web показує `MCP database is not ready`

Запусти:

```bash
php tasks/setup_db.php --admin-user=root --admin-password=ROOT_PASSWORD
```

### Немає admin password

Якщо проект створений через `init`, password надрукований у CLI output і записаний у `config/local.php`.

### `git status` каже `dubious ownership`

Якщо `.git` належить `root`, виправ ownership:

```bash
sudo chown -R nik:nik /var/apps/mcp/.git
```

Або одноразово:

```bash
git -c safe.directory=/var/apps/mcp -C /var/apps/mcp status
```

### MCP client не бачить tools

Перевір локально:

```bash
php mcp.php serve
```

Потім відправ JSON-RPC рядок:

```json
{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}
```

### MySQL write query блокується через MCP

Це очікувано. За замовчуванням `mysql_query` read-only. Для write queries:

```bash
MCP_ALLOW_UNSAFE_SQL=1 php mcp.php serve
```

## Production Checklist

- Змінити bootstrap admin password.
- Перевірити `config/local.php`.
- Запустити `tasks/setup_db.php`.
- Налаштувати Nginx root на `web/`.
- Створити users у `/access`.
- Зареєструвати всі потрібні web pages у `/access`.
- Не вмикати `MCP_ALLOW_UNSAFE_SQL`, якщо MCP-клієнту не потрібні write queries.
- Перевірити ownership проекту і `.git`.
